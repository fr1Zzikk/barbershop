# Зображення сайту

Ця папка призначена для локальних фото барбершопу.

Поточні фотографії залишаються завантажуваними з Unsplash, оскільки отримати їх локальні копії у цьому середовищі не вдалося. Дизайн і посилання на фото збережені, тому сайт виглядатиме як раніше за наявності інтернету.

Щоб зробити фото повністю локальними, збережи їх сюди й заміни URL в `index.html` та `css/style.css` на відносні шляхи (`images/назва.jpg` у HTML, `../images/назва.jpg` у CSS).
